# IsoLR

Separa una canzone in voce, batteria, basso e altri strumenti, **tutto sul computer**: niente server, niente abbonamento.
App per **Mac** (SwiftUI, macOS 14 o più recente) e per **Windows** (Tauri, Windows 10 e 11), più un sito che separa nel browser.

Il repository si chiama ancora **AudioLR**, il nome di prima di IsoLR.

## Scaricare
- Mac e Windows: [Rilasci](https://github.com/LR-apps609/AudioLR/releases) (`vX.Y.Z` per il Mac, `win-vX.Y.Z` per Windows)
- Mac dal Terminale, senza l'avviso di macOS:
  ```
  curl -fsSL https://raw.githubusercontent.com/LR-apps609/AudioLR/main/installa.sh | zsh
  ```
- Nel browser: https://lr-apps609.github.io/AudioLR/

Le app si aggiornano da sole.
